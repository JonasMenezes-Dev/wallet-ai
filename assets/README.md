# Identidade visual do Wallet.ai

Coloque aqui a imagem original da identidade visual com o nome:

`wallet_logo.png`

Este arquivo é a montagem de referência com as variações da marca. Depois que ele for adicionado, serão preparados arquivos separados para os usos do aplicativo, por exemplo:

- `icon.png`: ícone quadrado do aplicativo Android.
- `splash-icon.png`: símbolo para a tela de abertura do Expo.

Não configure o `app.json` para apontar para esses arquivos derivados antes de eles serem gerados e conferidos. A montagem `wallet_logo.png` será mantida como original de referência.
